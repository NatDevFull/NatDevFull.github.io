# 🌐 Developer Portfolio

Personal portfolio website showcasing my background, technical skills, projects, and development experience.

🔗 **Live website:** https://natdevfull.github.io/

## 📋 About the Project

This repository contains the source code of my personal developer portfolio.

The website was created to provide an overview of my technical skills and experience, while showcasing some of the projects I have worked on during my studies and personal development.

It serves as both a personal portfolio and a central place to explore my projects.

## ✨ Features

* 👨‍💻 Developer profile and introduction
* 🛠️ Technical skills and technologies
* 🚀 Project showcase
* 💼 Professional experience
* 🎓 Education
* 📫 Contact information
* 📱 Responsive design

## 🧰 Technologies

The website is built using:

* HTML5
* CSS3
* JavaScript

Additional technologies and libraries may be used depending on the different sections of the website.

## 🌍 Deployment

The website is hosted using **GitHub Pages** and is available at:

**https://natdevfull.github.io/**

Changes pushed to the repository can be deployed through GitHub Pages.

## 📌 Purpose

The main goals of this project are to:

* Present my developer profile
* Showcase my projects
* Demonstrate my web development skills
* Provide an easy way for recruiters and other developers to discover my work
